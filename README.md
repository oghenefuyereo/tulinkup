# Overview

I am a software engineer and the founder of Inovenatic Group, a digital solutions company registered in Ontario, Canada. Inovenatic helps businesses of all sizes establish and strengthen their online and physical presence through software development, branding, and digital services to improve their visibility, sales, and revenue.

TuLinkUp is an educational technology product under Inovenatic Group, designed to connect students with tutors and make academic support more accessible. I launched the TuLinkUp website with a waitlist in September 2026 to introduce the platform and generate interest. Developing this application is an opportunity to transform that initial concept into a functional software product while expanding my programming knowledge.

I am using JavaScript to develop the application's core functionality, including managing tutor information, processing user interactions, and building features that will allow students to discover tutors based on their learning needs. This work provides practical experience with JavaScript syntax and programming concepts such as variables, functions, arrays, objects, conditional statements, loops, and asynchronous operations.

My purpose for developing TuLinkUp is to deepen my understanding of JavaScript, strengthen my problem-solving skills, and gain experience writing clean, reusable, and maintainable code. As I continue building the platform, I want to apply what I learn to create reliable software solutions that solve real-world problems and support the long-term growth of Inovenatic Group.

# Development Environment

I developed TuLinkUp using Visual Studio Code on macOS, with Git and GitHub for version control and source code management.

The application is built using JavaScript (ES6+) as the primary programming language. I used Node.js and Express.js for backend development, Next.js and React for the frontend, and Tailwind CSS for responsive styling. Supabase provides a cloud-hosted PostgreSQL database for managing application data, while npm is used to install and manage project dependencies.

This development environment allows me to practice JavaScript programming, database integration, and full-stack web application development.
